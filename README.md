# Hotel Booking System

Một hệ thống đặt phòng khách sạn đơn giản với giao diện HTML tĩnh.

## Cấu trúc thư mục

- `index.html`: Trang chủ
- `public/`: Các trang dành cho khách hàng
- `admin/`: Các trang quản trị dành cho admin
- `assets/css/`: File CSS cho giao diện public và admin
- `assets/js/`: File JavaScript chung
- `assets/images/`: Tài nguyên hình ảnh

## Mục tiêu

- Hiển thị danh sách phòng
- Chức năng đặt phòng và xem chi tiết
- Trang đăng nhập, đăng ký và thông tin cá nhân
- Trang quản trị quản lý phòng, đặt phòng, khách hàng

## Khởi chạy

Mở trực tiếp file `index.html` trong trình duyệt hoặc sử dụng máy chủ tĩnh như `python -m http.server`.
